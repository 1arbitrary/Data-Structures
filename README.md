# Data-Structures

A personal repository for learning and implementing **Data Structures using The C Programming Language**.

This repo is focused on understanding how things work **at a low level**.

---

## About

This repository contains implementations of common data structures written in **C**, built from scratch to understand:

- Memory management
- Pointers and references
- Time and space trade-offs
- How high-level data structures actually work under the hood

The goal is learning, not perfection.

---

## Why C?

C forces you to think about:

- Manual memory allocation and deallocation
- Pointer manipulation
- Data layout in memory
- Performance implications of design choices

Implementing data structures in C builds strong fundamentals that transfer well to other languages.

---

## Data Structures Covered

Depending on progress, this repo may include:

- Arrays
- Linked Lists (Singly / Doubly)
- Stacks
- Queues
- Trees
- Hash Tables
- Graphs
- Basic algorithms related to these structures

(Some implementations may be incomplete or revised later.)

---

## Repository Structure

- Each data structure usually has its own folder or source file
- Implementations are kept simple and readable
- Code may evolve as understanding improves

There is no strict structure — clarity and learning come first.

---

## Notes

- Code may not be fully optimized
- Error handling may be minimal in early implementations
- Older files may reflect beginner-level understanding
- Refactors are expected and encouraged

This repository documents **progress over time**, not a final library.

## Purpose

This repo exists to:
