# Data Structures in C & C++

A personal repository for learning and implementing **Data Structures using C and C++**.

This repo focuses on understanding how data structures work **at a low level**, while also exploring how C++ builds on those foundations.

---

## About

This repository contains implementations of common data structures written from scratch in **C and C++** to deeply understand:

* Memory management
* Pointers and references
* Data layout in memory
* Time and space complexity trade-offs
* How high-level abstractions are built internally

The goal is **learning and clarity**, not production-ready perfection.

---

## Why C and C++?

### C — The Foundation

C forces you to think about:

* Manual memory allocation and deallocation
* Pointer arithmetic and manipulation
* Struct-based data modeling
* How data is physically arranged in memory
* Performance implications of every design decision

Implementing data structures in C builds strong core fundamentals that transfer to nearly every other language.

### C++ — Structured Abstraction

C++ builds on C by introducing:

* Classes and object-oriented design
* Constructors and destructors (RAII)
* Templates (generic data structures)
* The Standard Template Library (STL) for comparison with custom implementations

This allows exploration of **both low-level control and higher-level design patterns**.
